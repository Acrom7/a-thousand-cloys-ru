# Выпуск ZIP

Тег `v1`, `v2` и далее соответствует версии перевода. При изменении русского текста для следующего выпуска пересоберите ZIP. GitHub Actions проверяет PR, `main` и теги. Команда ниже использует локальные файлы конкретной Steam-сборки и формирует архив для **Releases**.

## Сборка на Windows

Нужны Steam Windows 1.0.3 (Build ID `26852255`), оригинальный архив модификации `A-Thousand-Cloys-RU-Steam-1.0.3-v1.zip` и Python 3.10. Базовый ZIP содержит уже проверенные патчи кода и шрифтов. SHA-256 этого базового ZIP записан в `game-build.json`. Скрипт берёт оригиналы из Steam или из проверенной `.atc-ru-backup` при установленном русификаторе.

Выполните из корня репозитория:

~~~powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe scripts\build_release.py --game-dir "D:\SteamLibrary\steamapps\common\A Thousand Cloys" --base-zip "D:\Downloads\A-Thousand-Cloys-RU-Steam-1.0.3-v1.zip" --revision v2
~~~

В `dist` появятся ZIP и отдельный файл SHA-256. Сборка меняет русский слот в бандле локализации, пересчитывает CRC локализации и шрифтов в каталоге Unity и проверяет повторное применение новых патчей. Поддержка обновления с v1 и тестовых сборок уже учтена. Для обновления поверх следующих выпусков добавляйте `--previous "путь к предыдущему ZIP"`, параметр можно повторить.

## Перед публикацией

- Проверьте, что ZIP собран из коммита, на который указывает тег и для которого прошёл CI.
- Установите новый ZIP на чистую тестовую копию, попробуйте обновление с предыдущего выпуска и удаление. Сверьте восстановленные хеши.
- При правках текста проверьте изменённые места в игре. Для клавиш, шрифтов и кода нужна отдельная игровая проверка.
- Откройте **Releases → Draft a new release**, выберите тег и приложите ZIP и `.zip.sha256`. В описании укажите совместимую сборку игры и изменения перевода. После публикации откройте ссылку скачивания.

Версии UnityPy и lz4 закреплены для повторяемой пересборки. Патчи, исходные бинарные файлы и сохранения остаются вне git. Новая сборка игры, новые глифы или правки кода требуют обновления базы мода, проверки совместимости и нового исходного ZIP.
