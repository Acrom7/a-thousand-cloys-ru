# A Thousand Cloys — русский перевод

Любительская русская локализация для Steam под Windows. Мод v2 проверен на игре 1.0.4, Build ID `26923816`. Переведены меню, настройки, обучение, письма и описания игровых объектов. Кириллица использует встроенный пиксельный шрифт Nihonium113.

## Скачать и установить

Скачайте ZIP из [последнего выпуска на GitHub](https://github.com/Acrom7/a-thousand-cloys-ru/releases/latest).

1. Закройте игру. Если устанавливали патч v1, сначала выполните шаги из раздела «Переход с v1».
2. Через **Управление → Просмотреть локальные файлы** откройте папку с `AThousandCloys.exe`.
3. Распакуйте туда содержимое `A-Thousand-Cloys-RU-Windows-v2.zip` и запустите игру через Steam. Архив включает BepInEx 5.4.23.5 x64. Если BepInEx 5 уже работает, используйте `A-Thousand-Cloys-RU-BepInEx-v2.zip`.

Мод подключается к английскому слоту. Если выбран французский, переключите язык на «Русский» в меню игры. Новую версию перевода распакуйте в ту же папку.

## После обновления игры

Мод накладывает перевод при запуске и оставляет новые или изменённые строки на английском. Пока загрузчик совместим, переустановка после обновления Steam обычно не требуется. Если мод не распознает интерфейс локализации, он пропустит перевод и запишет причину в `BepInEx/LogOutput.log`.

Чтобы вернуть английский, установите `Enabled = false` в `BepInEx/config/com.acrom7.atc.russian.cfg` и перезапустите игру. Чтобы удалить мод, закройте игру и удалите `BepInEx/plugins/ATC-Russian`. Настройка языка игры сохраняется в штатном формате.

Если после обновления игры перестал работать сам загрузчик, установите `enabled = false` в секции `[General]` файла `doorstop_config.ini` и перезапустите игру.

## Предложить правку

Откройте [`locales/ru.json`](locales/ru.json), нажмите ✎ и предложите изменение через pull request. Для сообщения о проблеме приложите ключ строки либо скриншот и напишите, где в игре виден текст.

- Сохраняйте ключи и подстановки вроде `%amount%`, `[%Input:MultiBuy%]` и `<h>…</h>`. Для трёх служебных ключей оставляйте `null`.
- Придерживайтесь [глоссария](docs/glossary.md). Если меняете термин, проверьте связанные строки.
- В PR запустится GitHub Actions. Он проверит наличие ключей, подстановки, теги и символы шрифта.

Локальная проверка работает на Python 3.10 без дополнительных библиотек:

~~~powershell
py -3.10 scripts/validate_translation.py
py -3.10 -m unittest discover -s tests
~~~

Готовый мод собирается из локальных файлов Steam по [инструкции выпуска](docs/release.md). В репозитории лежат русский текст, плагин и код сборки.
