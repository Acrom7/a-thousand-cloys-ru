# Русификатор v1

Для A Thousand Cloys 1.0.3 в Steam для Windows, Build ID 26852255. Первый публичный выпуск. В русском словаре 847 переведённых строк.

- Уточнили, что клои по сюжету — многофункциональные тостеры.
- Исправили пять штатных клавиш, которые могли отображаться как «??» в русской раскладке. Старые штатные назначения исправляются при загрузке. Пользовательские переназначения сохраняются.

Скачайте ZIP, полностью распакуйте, закройте игру и запустите Install-RU.cmd. Для удаления запустите Uninstall-RU.cmd из этого же архива. Подробности есть в README внутри ZIP.
