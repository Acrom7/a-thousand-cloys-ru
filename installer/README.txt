# A Thousand Cloys — русская локализация

Для Windows-версии Steam 1.0.3, Build ID 26852255 (App ID 3861740). Переведены 847 строк локализации, в том числе письма, обучение, интерфейс и описания объектов. В шрифты добавлена кириллица. В меню язык называется «Русский».

При загрузке сохраняются пользовательские переназначения. Установщик поддерживает обновление с выпусков, указанных в манифесте. Для обновления используйте Install-RU.cmd из нового архива. Для отката используйте Uninstall-RU.cmd из установленной ревизии.

## Установка

1. Закройте игру и распакуйте весь ZIP в любую обычную папку.
2. В библиотеке Steam щёлкните по A Thousand Cloys правой кнопкой мыши и выберите «Управление» → «Просмотреть локальные файлы». Скопируйте путь к папке, где лежит AThousandCloys.exe.
3. Запустите Install-RU.cmd из распакованного архива, вставьте путь к игре и нажмите Enter. После сообщения об успешной установке запускайте игру обычной кнопкой Steam.
4. Если в меню выбран Français, переключите язык стрелками внизу.

Установщик проверяет контрольные суммы и меняет шесть файлов в папке игры. Для применения патчей нужны исходные файлы указанной сборки. Сохранения и настройки остаются в штатном профиле игры.

## Удаление и обновления игры

Закройте игру, запустите Uninstall-RU.cmd и укажите ту же папку. Скрипт восстановит файлы из .atc-ru-backup, которую создал при установке. Сохраните распакованный архив и эту папку до удаления мода.

Если установка или удаление прерваны, повторите ту же операцию. Если Steam уже обновил игру, используйте «Свойства» → «Установленные файлы» → «Проверить целостность файлов игры». Обновление или проверка файлов через Steam могут восстановить оригиналы. Для новой сборки нужен совместимый патч.

## Проверка

Оригинальные игровые файлы и сохранения в ZIP отсутствуют. В архиве находятся скрипт, манифест контрольных сумм и бинарные различия. Для установки используется штатный Windows PowerShell.
