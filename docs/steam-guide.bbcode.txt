Название: Русификатор A Thousand Cloys — скачивание и установка
Язык: Русский
Категория: Модификации или настройка (Modding or Configuration)

[h1]Что переведено[/h1]
Меню, настройки, обучение, письма и описания игровых объектов. В русификатор добавлена кириллица и исправлены штатные горячие клавиши, которые могли показываться как «??» в русской раскладке.

[b]Русификатор v3 проверен на Steam-версии 1.0.5 для Windows, Build ID 26970711.[/b] Кириллица использует встроенный пиксельный шрифт Nihonium113.

В v3 переведены все 850 игровых строк. В настройках управления появилась команда «Выполнить основное действие выбранного объекта» (по умолчанию X), а подсказка о маяках теперь упоминает сильный ветер.

[h1]Где скачать[/h1]
Откройте [url=https://github.com/Acrom7/a-thousand-cloys-ru/releases/latest]последний выпуск на GitHub[/url] и скачайте в разделе Assets архив A-Thousand-Cloys-RU-Windows-v3.zip. Если BepInEx 5 уже работает в папке этой игры, можно взять A-Thousand-Cloys-RU-BepInEx-v3.zip.

[h1]Установка[/h1]
[olist]
[*]Закройте игру. Если устанавливали v1, сначала выполните шаги из раздела «Переход с v1» ниже.
[*]В библиотеке Steam щёлкните по A Thousand Cloys правой кнопкой мыши и выберите «Управление» → «Просмотреть локальные файлы».
[*]Распакуйте содержимое ZIP прямо в папку с AThousandCloys.exe. Загрузчик уже входит в Windows-архив.
[*]Запустите игру через Steam. При необходимости выберите «Русский» стрелками внизу главного меню.
[/olist]

[h1]Переход с v1[/h1]
v1 заменял файлы игры. Закройте игру, в Steam откройте «Свойства» → «Установленные файлы» → «Проверить целостность файлов игры» и дождитесь завершения проверки и загрузки. Steam восстановит оригиналы для установленной версии игры. Папку .atc-ru-backup можно оставить. Теперь распакуйте v3 по инструкции выше.

[h1]После обновления игры[/h1]
Мод подключает перевод при запуске и оставляет новые или изменённые строки на английском. Пока загрузчик совместим, после обновления Steam обычно достаточно запустить игру. Если мод не распознает интерфейс локализации, он пропустит перевод. Причина появится в BepInEx/LogOutput.log.

Чтобы обновиться с v2, закройте игру и распакуйте архив v3 в ту же папку с заменой файлов. Если после обновления игры перестал запускаться сам загрузчик, временно установите enabled = false в секции [General] файла doorstop_config.ini.

[h1]Как убрать перевод[/h1]
Для v2 и v3 закройте игру и удалите папку BepInEx/plugins/ATC-Russian. Чтобы временно вернуть английский, установите Enabled = false в BepInEx/config/com.acrom7.atc.russian.cfg и перезапустите игру. Для v1 восстановите файлы по разделу «Переход с v1».

[h1]Поправить перевод или сообщить об ошибке[/h1]
[url=https://github.com/Acrom7/a-thousand-cloys-ru]Перевод и инструкции на GitHub[/url]. Можно предложить правку в locales/ru.json. Для сообщения об ошибке укажите версию мода и экран, на котором видна проблема, и по возможности приложите скриншот.
