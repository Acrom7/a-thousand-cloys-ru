# A Thousand Cloys — русский перевод

Любительская русская локализация для Steam-версии под Windows, игра 1.0.3, Build ID 26852255. Переведены меню, настройки, обучение, письма и описания игровых объектов.

## Скачать и установить

1. В [Releases](https://github.com/Acrom7/a-thousand-cloys-ru/releases/latest) откройте **Assets** и скачайте архив `A-Thousand-Cloys-RU-Steam-1.0.3-v*.zip`.
2. Закройте игру и полностью распакуйте ZIP.
3. В Steam откройте **Библиотека → A Thousand Cloys → Управление → Просмотреть локальные файлы**. Скопируйте путь к папке с `AThousandCloys.exe`.
4. Запустите `Install-RU.cmd` из распакованного архива, вставьте путь и дождитесь сообщения об успехе. Запустите игру из библиотеки Steam. В главном меню можно выбрать «Русский».

Для удаления запустите `Uninstall-RU.cmd` **из архива установленной ревизии** и укажите ту же папку. Исходные файлы лежат в `.atc-ru-backup` внутри папки игры. После обновления игры проверьте, поддерживается ли новая сборка.

## Предложить правку

Откройте [`locales/ru.json`](locales/ru.json), нажмите ✎ и предложите изменение через pull request. Для сообщения о проблеме приложите ключ строки либо скриншот и напишите, где в игре виден текст.

- Сохраняйте ключи и подстановки вроде `%amount%`, `[%Input:MultiBuy%]` и `<h>…</h>`. Для трёх служебных ключей оставляйте `null`.
- Придерживайтесь [глоссария](docs/glossary.md). Если меняете термин, проверьте связанные строки.
- В PR запустится GitHub Actions. Он проверит наличие ключей, подстановки, теги и символы шрифта.

Локальная проверка работает на Python 3.10 без дополнительных библиотек:

~~~powershell
py -3.10 scripts/validate_translation.py
py -3.10 -m unittest discover -s tests
~~~

Готовый мод собирается из локальных файлов Steam по [инструкции выпуска](docs/release.md). В репозитории лежат русский текст, установщик и код сборки.
